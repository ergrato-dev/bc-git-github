# 🎓 Certificaciones GitHub - Guía del Bootcamp

## 📋 Descripción General

Este bootcamp de 16 semanas está diseñado específicamente para preparar a los estudiantes para las **4 certificaciones oficiales de GitHub**, cubriendo desde fundamentos hasta administración empresarial.

## 🏅 Certificaciones Disponibles

### 1. GitHub Foundations Certification

**Duración de preparación:** Semanas 1-6  
**Nivel:** Principiante  
**Temas cubiertos:**

- ✅ Git fundamentals y version control
- ✅ Repository management y collaboration
- ✅ Branching strategies y merge workflows
- ✅ GitHub features (Issues, PRs, Projects)
- ✅ Community management y documentation

**Examen:** 75 preguntas, 2 horas, 70% para aprobar

### 2. GitHub Actions Certification

**Duración de preparación:** Semanas 7-10  
**Nivel:** Intermedio  
**Temas cubiertos:**

- ✅ Workflow authoring y maintenance
- ✅ CI/CD pipeline implementation
- ✅ Custom actions development
- ✅ Enterprise Actions management
- ✅ Security y best practices

**Examen:** 75 preguntas, 2 horas, 70% para aprobar

### 3. GitHub Advanced Security Certification

**Duración de preparación:** Semanas 11-13  
**Nivel:** Avanzado  
**Temas cubiertos:**

- ✅ Code scanning y SAST implementation
- ✅ Dependency management y vulnerability detection
- ✅ Secret scanning y prevention
- ✅ Security advisories y policies
- ✅ Compliance y audit logging

**Examen:** 75 preguntas, 2 horas, 70% para aprobar

### 4. GitHub Administration Certification

**Duración de preparación:** Semanas 14-15  
**Nivel:** Experto  
**Temas cubiertos:**

- ✅ Organization y enterprise management
- ✅ User authentication y access control
- ✅ Repository governance y policies
- ✅ Audit logging y compliance
- ✅ Enterprise security configuration

**Examen:** 75 preguntas, 2 horas, 70% para aprobar

## 🎯 Estrategia de Estudio

### Semanas 1-6: Foundations

1. **Práctica diaria** con comandos Git básicos
2. **Proyectos colaborativos** simulando equipos reales
3. **Simulacro semanal** con 15 preguntas

### Semanas 7-10: Actions

1. **Workflows prácticos** en diferentes lenguajes
2. **Custom actions** development
3. **Simulacro semanal** con 15 preguntas

### Semanas 11-13: Security

1. **Security scanning** en repositorios reales
2. **Vulnerability management** hands-on
3. **Simulacro intensivo** con 25 preguntas

### Semanas 14-15: Administration

1. **Enterprise setup** simulation
2. **Policy implementation** práctica
3. **Simulacro completo** 75 preguntas

### Semana 16: Repaso Final

1. **Mock exams** para las 4 certificaciones
2. **Weak points** identification y refuerzo
3. **Strategy planning** para exámenes reales

## 🏆 Criterios de Éxito

Para cada certificación, el estudiante debe:

- ✅ **85%+ en simulacros** durante las semanas de preparación
- ✅ **Proyectos prácticos completados** con calificación mínima de 80%
- ✅ **Participación activa** en ejercicios colaborativos
- ✅ **Dominio de herramientas** específicas de cada certificación
