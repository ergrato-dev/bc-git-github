# 🚀 Week 02: Repositories y Commits

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana serás capaz de:

- ✅ Dominar el staging area y su funcionamiento
- ✅ Crear commits efectivos con mensajes descriptivos (Conventional Commits)
- ✅ Navegar por el historial de commits con git log
- ✅ Entender los diferentes estados de archivos en Git
- ✅ Usar comandos de inspección: diff, show, log
- ✅ Deshacer cambios de forma segura

---

- ✅ Completar Week 01
- ✅ Git instalado y configurado
- ✅ Identidad configurada (nombre y email)
