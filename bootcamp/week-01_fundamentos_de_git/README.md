# 🚀 Week 01: Fundamentos de Git

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana serás capaz de:

- ✅ Comprender qué es el control de versiones y por qué es esencial

- ✅ Configurar tu identidad y preferencias en Git
- ✅ Inicializar y trabajar con tu primer repository
- ✅ Entender el flujo básico de trabajo con Git

- Computadora con Windows, macOS o Linux

## 📌 Entregables

### Obligatorios

1. **Git instalado y configurado** - Captura de `git --version` y `git config --list`
2. **Repository local** - Con mínimo 3 commits significativos
3. **Archivo .gitignore** - Configurado apropiadamente para el proyecto

### Opcionales

- Reflexión escrita sobre la importancia del control de versiones
- Diagrama del flujo de trabajo Git

---

## 🎓 Conceptos Clave

| Concepto | Descripción |
|----------|-------------|
| **Repository** | Carpeta que contiene el historial de cambios de un proyecto |
| **Commit** | Instantánea de los cambios en un momento específico |
| **Staging Area** | Área de preparación antes de hacer commit |
| **Working Directory** | Tu carpeta de trabajo actual |

## 💡 Consejos para Esta Semana

1. **No tengas miedo de experimentar** - Git te permite deshacer cambios
2. **Practica los comandos** - La repetición es clave para memorizar
3. **Lee los mensajes de error** - Git es muy descriptivo en sus errores
4. **Usa la documentación** - `git help <comando>` es tu amigo
