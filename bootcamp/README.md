# 🛠️ Bootcamp Git/GitHub - Trabajo Efectivo

Esta carpeta contiene todo el material de trabajo práctico semanal del bootcamp de 16 semanas.

## 📅 Estructura Semanal

Cada semana sigue una estructura estandarizada:

```
week-NN_slug/
├── README.md               # Descripción general de la semana
├── rubrica-evaluacion.md   # Criterios de evaluación específicos
├── 0-assets/                # Imágenes, diagramas y assets de la semana
├── 1-teoria/                # Lecciones y conceptos teóricos
├── 2-practicas/              # Prácticas guiadas paso a paso
├── 3-proyecto/               # Proyecto integrador de la semana
└── 4-recursos/                # Material complementario semanal
```

## 🎯 Fases del Bootcamp

### 📘 Fase 1: GitHub Foundations (Semanas 1-6)

- **Objetivo**: Dominio completo de Git y GitHub básico
- **Certificación**: GitHub Foundations

### 🔧 Fase 2: GitHub Actions (Semanas 7-10)

- **Objetivo**: Automatización CI/CD con GitHub Actions
- **Certificación**: GitHub Actions

### 🛡️ Fase 3: GitHub Advanced Security (Semanas 11-13)

- **Objetivo**: Seguridad, vulnerability management y compliance
- **Certificación**: GitHub Advanced Security

### 👥 Fase 4: GitHub Administration (Semanas 14-15)

- **Objetivo**: Administración enterprise, organizations, teams y permisos
- **Certificación**: GitHub Administration

### 🎓 Fase 5: Proyecto Final & Certificaciones (Semana 16)

- **Objetivo**: Proyecto integrador y preparación final para las 4 certificaciones
- **Certificación**: Todas

## 📋 Instrucciones de Uso

1. **Para Instructores**: Cada semana tiene material completo listo para usar
2. **Para Estudiantes**: Seguir la numeración secuencial (1-teoria, 2-practicas, 3-proyecto, 4-recursos)
3. **Evaluación**: Usar las rúbricas específicas de cada semana (`rubrica-evaluacion.md`)
