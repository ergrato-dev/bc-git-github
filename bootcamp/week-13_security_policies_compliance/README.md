| Framework | Enfoque | Industria |
|-----------|---------|-----------|

| GDPR | Data Privacy | EU/Global |
| HIPAA | Healthcare Data | Healthcare |
| PCI-DSS | Payment Data | Finance/Retail |
| ISO 27001 | ISMS | Global |

### GHAS Enterprise Features

- **Security Overview**: Dashboard organizacional
- **Security Policies**: Policies a nivel org/enterprise
- **Rulesets**: Branch protection con security requirements
- **Audit Log**: Compliance reporting
